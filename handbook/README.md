# Supervisor-Skills Handbook
# Based on: https://github.com/HKUSTDial/Supervisor-Skills (CC BY-NC-SA 4.0)

This directory contains the research methodology handbook from the Supervisor-Skills
project by Yuyu Luo at HKUST(GZ). It provides a systematic theoretical framework
for deep reading and study covering the full research lifecycle.

## Chapters

| Chapter | Content |
|---|---|
| 01_Preliminary | Evaluating paper quality from a reviewer's perspective |
| 02_Idea_Generation | Idea lifecycle, five-dimension thinking, disruptive innovation |
| 03_Paper_Writing | Paper lifecycle, Introduction flowchart, technical and benchmark templates, writing checklist |
| 04_Scientific_Plotting | Motivated, overview, experimental figures and drawing checklist |
| 05_Vibe_Research | AI-assisted research workflow and practitioner notes |
| 06_Case_Studies | Alpha-SQL (ICML 2025), AFlow (ICLR 2025), LEAD (VLDB 2026) |

## Integration with Academic Research Agent

The handbook content informs the agent's six research skill modules:
- **IdeaEvaluator** → Chapter 2 (Idea Generation)
- **PaperPlanner** → Chapter 3 (Paper Writing templates)
- **IntroDrafter** → Chapter 3.2 (Introduction flowchart)
- **FigureDesigner** → Chapter 4 (Scientific Plotting)
- **PaperReviewer** → Chapters 1.1 + 3.5 (Quality evaluation + Writing checklist)
- **ResearchWorkflow** → Chapter 5 (Vibe Research)
